About QuickNotes

QuickNotes is a simple app for capturing short notes quickly. It helps you keep your ideas, tasks and reminders in one easy place.

How to use QuickNotes

  1. Open the QuickNotes page.
  2. Type your note into the text box.
  3. Click the save button to store your note.

Features

  • Fast note creation
  • Simple, clean layout
  • Easy to read on any device

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the note
